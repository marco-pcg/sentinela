# Attribution and licensing status

This fork is derived from [noemicho/sentinela](https://github.com/noemicho/sentinela), reviewed at commit `81b19f0619d9327ad1341c231a4a53ca5889d4fe`. The original contributors retain their rights in their work. Existing experiment notebooks and the bundled model are preserved with attribution.

At the reviewed revision, the upstream repository did not include a top-level license. This fork does not grant or invent a license for that material. A public repository or the ability to create a GitHub fork does not establish broad reuse/redistribution permissions. Clarifying a source license with the rights holders is a release blocker; the project should not yet be described as fully licensed open source.

The bundled checkpoint contains an embedded `AGPL-3.0 (https://ultralytics.com/license)` metadata string. Ultralytics has its own licensing requirements; that string does not determine the rights in all project source, training images or annotations. Dependencies retain their respective licenses.

Before redistribution or a packaged release, maintainers need to document the source license, model provenance and terms, dataset rights/consent, and applicable upstream obligations. No ownership or consent claim about the missing dataset is made here.
